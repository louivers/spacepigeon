# SpacePigeon: Saved Workspaces for macOS (Hammerspoon-based)

**SpacePigeon** lets you define *workspaces* for macOS — which apps open, which desktop spaces they go to, and how windows are arranged — using a single simple `init.lua` script for Hammerspoon.

## Features
- Open specific apps into specific macOS Spaces  
- Auto-arrange windows  
- Trigger workspaces via hotkeys  
- Written entirely in Hammerspoon Lua  
- Lightweight and open-source  

## Installation
1. Install [Hammerspoon](https://www.hammerspoon.org/)
2. Copy `init.lua` into your `~/.hammerspoon` directory
3. Reload Hammerspoon
